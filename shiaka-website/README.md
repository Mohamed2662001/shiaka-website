# Shiaka official website starter

Static bilingual-ready website for Cloudflare Pages.

## Preview locally
Open `index.html` in a browser.

## Deploy to Cloudflare Pages
1. Create a GitHub repository and upload all files in this folder.
2. In Cloudflare Dashboard, open **Workers & Pages** → **Create** → **Pages** → **Connect to Git**.
3. Select the repository.
4. For this plain HTML/CSS/JS project, use:
   - Framework preset: None
   - Build command: leave empty
   - Build output directory: `/` (or `.` if the UI requires it)
5. Deploy. Then add `shiakaapp.com` and `www.shiakaapp.com` under the Pages project's Custom domains.

## Before public launch
- Replace the temporary text logo with the official PNG in `assets/` and update the header/footer markup.
- Complete and legally review `privacy.html` and `terms.html`; the current pages are drafts only.
- Add real support/contact details.
- Confirm every statement about delivery, ordering, payment, cancellation and returns matches actual product behavior.
- Test Arabic/English, mobile layout, navigation, and all links.
